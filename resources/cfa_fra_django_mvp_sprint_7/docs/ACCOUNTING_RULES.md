# Règles comptables minimales

1. Une ligne porte soit un débit, soit un crédit.
2. Les montants sont positifs ou nuls.
3. Une écriture comporte au moins deux lignes.
4. Total débit = total crédit avant posting.
5. Une période CLOSED interdit le posting.
6. Une écriture POSTED n'est pas modifiée directement.
7. Une correction utilise une extourne.
8. Les calculs monétaires utilisent Decimal.
9. Les états financiers sont calculés depuis le journal.
10. Un FEC importé conserve le fichier original et les lignes brutes.
