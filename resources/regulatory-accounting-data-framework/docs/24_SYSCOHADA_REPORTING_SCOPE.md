# Reporting — périmètre source

Le Guide précise quatre états financiers : Bilan, Compte de résultat, Tableau des flux de trésorerie et Notes annexes.

Application 127 fournit un modèle exemple et autorise la suppression des rubriques/postes sans valeur.

Le Guide indique aussi que les grilles exhaustives Postes/Comptes figurent au Plan comptable général OHADA Titre IX chapitre 7.

Ces tables ne figurent pas dans le corpus disponible. La release ne les reconstitue pas par heuristique.
