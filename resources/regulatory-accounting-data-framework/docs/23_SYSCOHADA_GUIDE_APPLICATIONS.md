# Applications du Guide

Chaque application conserve :
- numéro canonique ;
- numéro imprimé dans le corps ;
- mode de résolution ;
- titre source et titre du sommaire ;
- pages PDF ;
- texte complet ;
- mentions de comptes ;
- résolution éventuelle d'une subdivision locale.

Les applications sont regroupées :
- 1–24 : opérations courantes ;
- 25–126 : opérations et problèmes spécifiques ;
- 127 : états financiers ;
- 128–142 : consolidation et combinaison.
