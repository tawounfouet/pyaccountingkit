# Politique de validation ORCOM

Le plan ORCOM est utile pour :

- comparer la couverture pratique ;
- repérer des variations de libellés ;
- repérer des codes historiquement ambigus ;
- identifier des écarts à investiguer.

Il ne constitue pas une source réglementaire primaire.

## Statuts de comparaison

```text
label_match
label_variation
duplicate_code_meaning_in_practitioner_reference
missing_from_practitioner_reference
practitioner_extra_not_in_canonical_effective_plan
```

## Cas 102

ORCOM documente deux finalités historiques du code 102. Le framework conserve cette duplication comme observation de référence praticien, sans créer automatiquement deux comptes réglementaires dans le plan effectif.

## Temporalité

```text
ORCOM       : 2025
ANC canonique: 2026
```

Tout écart doit donc être revu contre la source ANC 2026 avant conclusion.
